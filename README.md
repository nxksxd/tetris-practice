# 🎮 Tetris Practice



Консольная версия игры «Тетрис», разработанная в рамках технологической (проектно-технологической) практики по направлению 09.03.03 «Прикладная информатика».



---



## 📌 Описание проекта



Программа реализует базовую игровую механику классического Тетриса в консольном режиме.



Игра разработана на языке C# с использованием .NET.



---



## ⚙ Реализованные возможности



\- Игровое поле 10x20

\- Падающие фигуры (квадрат и линия)

\- Движение фигур:

&nbsp; - ⬅ Влево

&nbsp; - ➡ Вправо

&nbsp; - ⬇ Вниз

&nbsp; - ⬆ Вращение

\- Проверка столкновений

\- Очистка заполненных линий

\- Проверка окончания игры (Game Over)

\- Основной игровой цикл



---



## 🛠 Используемые технологии



\- C#

\- .NET

\- Console Application

\- Visual Studio



---



## 🚀 Как запустить



1\. Открыть файл `TetrisPractice.sln` в Visual Studio

2\. Нажать \*\*Start (F5)\*\*

3\. Управлять стрелками клавиатуры
